What I work on

  • Reproducible GPU inference

    One model and one set of weights produced a different answer on every NVIDIA card it ran on. Owning the arithmetic order instead of the vendor library's made the output byte-identical across all nine — five architecture generations, two operating systems, one SHA-256.

  • Inferring an engine from the inside

    A game ships as an obfuscated Java binary whose class names change between releases. I inject code into its running JVM to read real state and issue real orders — no pixels, no synthetic input — and made runs bit-identical per seed, so a better strategy can be told apart from a lucky map.

  • MCP & agent infrastructure

    Thirteen services and twenty-two shared libraries in one repository, held together by 47 architecture rules that fail the build — design decisions enforced by CI rather than remembered in review. Written across Python and Rust, because an invariant that holds in one language isn't one.

  • Composing one model out of several

    A serving design assumed several separately trained compartments could be wired into one request. Measuring it first put the naive limit at two — and the run's own controls caught a result that read the right way and wasn't. A composition-aware recipe then moved four-compartment retention from −45.4% to +44.6%.

  • Research cluster infrastructure

    Eight research projects run on a shared university GPU cluster through one tool that will not let a job be built if it would fail, and can answer afterwards which job produced which artifact. Preflight that cannot be skipped, a budget the cluster itself does not enforce, and three failure conditions that look like health.

  • ClearGBM

    Gradient boosting written from scratch in numpy, ported to a Rust core, and then the numpy version deleted — roughly 10k lines — because two implementations can disagree. The first one was the oracle the port was checked against; scaffolding comes down.

  • LightGBM

    Nine merged pull requests — Python type annotations, a POSIX socket-timeout fix, and test coverage. Nine of twelve attempted, with the three that did not land in the distributed-training path.

  • SCiL 2026

    Co-author, Quantifying Mutual Intelligibility Gradients in Turkic Languages Using Language Models. Also accepted at HSP 2026 and Tu+11, both at MIT.
