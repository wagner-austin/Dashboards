# Lion animation assets

All eight animations depict one photographic golden-brown adult lion with a full mane. The September 14 revision replaces the mixture of photographic walk/idle frames and older blue cartoon jump/turn/depth frames.

The user's walk and idle GIF poses supplied the reference. The built-in image-generation tool consolidated those poses and the missing movements into `production_sheet.png`, giving the lion a fuller mane throughout. The final editing prompt is recorded in `production_prompt.txt`.

The walking cycle was subsequently replaced by eight joint-driven poses. Four textured limb meshes were animated in Blender with alternating paw contacts, planted backward travel, and lifted forward return. The resulting `lion_walk_animation/walk_pose_guide.png` supplied the exact foot positions for a seam-cleanup image edit; `walk_sheet.png` and `walk_prompt.txt` record that result and prompt. Walking frames are registered by the upper body, so leg movement does not shift the torso. The loop is eight frames at the existing 120 ms walk interval (0.96 seconds).

## Registration and size

The walk-to-idle transition reuses current walk frames 0 and 7, followed by idle frame 0. The engine reverses this clip for idle-to-walk, so startup now leads from idle through walk frame 7 into frame 0 without flashing the superseded gait poses. Rebuild these transition sources whenever the walk art changes.

- Every source frame is 640 × 400 on white, with a shared ground baseline near pixel 370.
- Standing poses share an approximately 300-pixel anatomical height. Gait phases use a shared cycle scale; front/rear views retain their naturally narrower bodies.
- Subjects were isolated as connected components, preventing a neighboring tail from entering a rectangular crop.
- Horizontal placement follows the body pixel centroid, so tail movement does not move the entire lion.
- Jump frames retain explicit lift and return to the idle pose. Both turning transitions begin with the exact idle pose.
- Configured ASCII width is 128, up from 96. All generated frames have 40 rows; standing/gait silhouettes occupy approximately 30 rows instead of the original photographic frames' 13–14.
- Right-facing modules are generated by mirroring the same sources. Superseded lion-size modules are removed when the configured size changes.

## Existing conversion pipeline

From the `rabbit` directory, rebuild a GIF from its canonical PNG frames with:

```powershell
poetry run python -m scripts.frames_to_gif originals/lion/lion_walk_animation --output originals/lion/lion_walk_animation/walk.gif
```

Then regenerate the ASCII modules using the existing sprite generator and compile with `npm run build`. `config.json` identifies each source and its width/directions. The original generated sheet is provenance; the registered per-animation PNG/GIF files are the runtime build inputs.

Preview the deployed character at https://austinwagner.org/rabbit/?character=lion or inspect the animations individually at `/rabbit/preview.html`.
