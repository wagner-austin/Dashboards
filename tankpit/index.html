Every tank here is a separate process speaking TankPit's binary WebSocket protocol directly. The game publishes no API — position, fuel, rank and kills are all decoded from the wire, backed by about 75 pages of protocol notes.

The fleet plays the Practice room, which is consequence-free: no rank is at stake for anyone involved. doctrine is a bot's engagement policy and is fixed when its process starts, so changing it restarts that bot rather than toggling a setting.

This page reads one published snapshot and never reaches the machine the bots run on — a hundred viewers cost what one does.
